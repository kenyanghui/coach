什么是 DojoAgents？

深涌智能（Alpha-Dojo）开源的主动式金融 AI Agent 框架

核心定位

DojoAgents 是深涌智能（Alpha-Dojo）开源的主动式（自主式）AI Agent 框架， 定位为「个人投资的全市场 AI 副驾」（Full-Market AI Copilot）。 核心是 Loop-Driven Cognitive Portfolio Agent（循环驱动的认知组合智能体）， 通过 Agent 循环 引擎把市场扫描、新闻检索、公司分析、产业链映射、 组合构建和风险分析拆解为可自主调用的工具，串联成完整决策辅助流程。

与传统「被动问答」金融 AI 不同，DojoAgents 知道「下一步应该查什么、如何验证」， 主动推进研究与决策辅助任务——不再是「给出答案」，而是「主动推进」。

本机核验 · 快速部署

从“已经安装”到“可以交付”

本机已安装dojoagents 0.2.3；当前未发现~/.dojo/agents.yaml，第一课先完成模型与安全配置

1 新环境安装；本机可跳过
# 推荐使用uv隔离安装
uv tool install dojoagents

# 当前课程核验版本：dojoagents 0.2.3
2 先配置模型连接
# 交互式写入本地配置，不在课件中展示API密钥
dojoagents model --config ~/.dojo/agents.yaml
3 启动Dashboard并完成健康检查
# 轻量模式适合第一次课堂演示
dojoagents dashboard --host 127.0.0.1 --port 8765 --lightweight-runtime

# 浏览器访问 http://127.0.0.1:8765/
4 首个研究任务与证据导出
# CLI首跑：要求给出数据来源、时间戳与不确定性
dojoagents chat "分析一个跨市场主题，并列出证据、反例与下一步验证"

# 课程结束时导出会话证据
dojoagents sessions export --output-dir ./dojo-evidence

四课完成一条主动式投研链

目标不是让Agent给出“答案”，而是检查它如何找证据、如何纠错、如何留下可审计记录

LESSON 01
模型、数据与安全边界
完成模型配置，理解API密钥本地存储、数据授权、提示词边界和投资教育免责声明。
LESSON 02
Agent Loop研究链
给出跨市场研究问题，观察推理—工具—观察—再推理循环，并记录每个工具调用目的。
LESSON 03
Harness纠错与反例
故意提供缺失条件，检查Agent是否补证据、承认不确定性并在条件不足时停止。
LESSON 04
Gateway、MCP与SKILL
理解Gateway、MCP服务、会话导出和SKILL沉淀，设计一个可复用的盘后研究工作流。
课堂交付物

① 环境与版本清单 · ② 一条完整研究会话 · ③ 工具调用与纠错记录 · ④ 证据/推断/观点三栏报告 · ⑤ 一个自定义SKILL设计稿。
