什么是 QMT？

迅投（ThinkTrader）的本地化极速策略交易系统

核心定位

QMT（Quantitative Market Trading）是北京睿智融科控股（2011 年成立）旗下 迅投（ThinkTrader）品牌的极速策略交易系统，面向有编程能力的量化投资者与机构。 与恒生 PTrade 并称国内券商主推的两大量化终端，二者互补：QMT 主打本地运行 + 低延迟 + 全品种， PTrade 主打云端托管 + 易上手。

易混淆澄清：MindGo 是同花顺旗下的 AI 量化平台，与迅投 QMT 无关； 恒生对应的产品是 PTrade，也非 QMT。

属性详情
开发商北京睿智融科控股（2011 成立，品牌「迅投 ThinkTrader」，非上市）
产品定位面向有编程能力者的本地化极速交易终端
运行模式本地客户端运行，仅委托上传柜台（代码与数据不上云）
策略语言Python + VBA 双语言
交易品种A 股 / ETF / 可转债 / 两融 / 期货 / 期权 / 港股通 / 北交所
回测精度Tick 级 / 逐笔回测（完整版）
延迟本地直连极速柜台 + 全内存交易，宣传单笔 <1ms
开源情况xtquant 非开源，无官方 GitHub；第三方封装 EasyXT 等
监管合规受证监会《程序化交易管理规定》（2024-10 施行）约束
MiniQMT 是什么

MiniQMT = QMT 的「极简模式」

不是独立软件，而是允许外部 IDE + 外部 Python 自由开发的交易网关

维度完整版 QMTMiniQMT + xtquant
代码编写位置必须在 QMT 客户端内外部任意 IDE（PyCharm / VSCode / Jupyter）
Python 环境内置 Python 3.6，第三方库有限外部 64 位 Python 3.6–3.13，自由装库
回测自带可视化回测（含 Tick 级）无内置，需外接 backtrader 等
图形界面完整 UI精简，仅数据 + 交易网关
资源占用较高约标准版 30%
灵活性受客户端框架限制极高，可接数据库 / AI 模型 / 自建系统
登录与授权机制

必须先启动 MiniQMT 客户端并保持登录在线，xtquant 才能连接；客户端关闭策略即断。 策略代码无需上传，仅委托经本地客户端上传券商柜台。 xtdata（行情）无需登录即可用；xttrader（交易）需开通 A 股实盘版权限。 连接仅需提供资金账号，无需交易密码。

xtquant Python 库

数据 + 交易 · 双模块 API

MiniQMT 的核心，把行情与下单能力开放给外部 Python

📊
xtdata · 行情
历史 / 实时 / Tick / 财务
download_history_data()get_market_data_ex()subscribe_quote()get_full_tick()
💹
xttrader · 交易
报单 / 撤单 / 查询
order_stock()order_stock_async()cancel_order_stock()query_stock_positions()
1 安装 xtquant（三种方式）
# 方式一：pip（指向镜像或本地拷贝）
pip install xtquant

# 方式二：官网下载压缩包解压到 site-packages
# dict.thinktrader.net/nativeApi/download_xtquant.html

# 方式三：QMT 客户端「下载 Python 库」后拷贝
# bin.x64\Lib\site-packages
2 连接 MiniQMT 并下单
from xtquant import xtdata, xttrader
from xtquant.xttrader import XtQuantTrader
from xtquant.xttype import StockAccount

# path 指向 MiniQMT 安装目录的 userdata_mini 文件夹
trader = XtQuantTrader(path, session_id, callback)
trader.connect()
trader.subscribe(account)
trader.order_stock(account, "600000.SH", 23, 100, 11, 10.5, "策略名", "备注")
API 约定

代码格式 '600000.SH' / '000001.SZ'； period 支持 tick / 1m / 5m / 15m / 30m / 1h / 1d / 1w / 1mon； 下单 order_type 中 23=买、24=卖。 版本历史：240613 支持 Py3.12，250516 支持 Py3.13 + 银证转账，最新 250807。

竞品对比

QMT vs PTrade · 本地 vs 云端

核心区别：手动挡赛车 vs 智能电动车

维度QMT（迅投）PTrade（恒生）
运行模式本地客户端运行，仅委托上传券商云端服务器托管
语言Python + VBA仅 Python
延迟更低（微秒/亚毫秒级）毫秒级，适合中低频
第三方库可自由安装仅白名单内库
品种覆盖全品类（含期货/期权/港股通）现货为主，衍生品支持弱
回测精度Tick 级逐笔分钟级为主
策略数量理论上无上限模拟盘 ≤5、实盘 ≤8
策略保密性代码留在本地需上传券商服务器
硬件要求高（需常开 + 16G+ 固态）极低
上手门槛高（需编程+自运维）低（零代码模板 + 云端免运维）
QMT 像「手动挡专业赛车」，PTrade 像「顶级智能电动车」。二者非互斥，国金等券商支持「双开」组合使用。 —— 社区流传比喻
适用场景选择

选 QMT / MiniQMT：有编程能力、做期货/期权、高频/低延迟、策略复杂、对代码保密要求高、愿自维护服务器。
选 PTrade：新手/上班族、股票/ETF/可转债、中低频、要云端 7×24 免运维。

版本 · 收费 · 门槛

券商专业版免费 · 官方投研版付费

唯一能合规实盘的是券商专业版

版本收费说明
官方基础版付费无法实盘
官方投研版约 9780 元/年（+L2 约 2980 元）面向个人/机构，需注意实盘合规
券商测试版多数免费模拟盘
券商专业版免费（需资产门槛 + 程序化报备）完整功能，唯一能合规实盘
开通门槛（20 日日均资产 + C4 风险测评）

国金证券 0 门槛（限时）/ 10 万（散户最友好，可同开 PTrade、送 L2）； 江海 5 万起；华西/中金财富/国信约 10 万；中信建投/长城 20 万；华泰/中信 30–50 万； 头部全功能版 50–300 万。国盛偏高，多来源称 50 万以上甚至 100 万档。

重要提醒

国金「0 门槛」为限时政策；延迟的「微秒/纳秒级」属营销口径，真实延迟受柜台/网络/券商风控影响； 门槛与 MiniQMT 支持情况以开户券商客户经理确认为准，开通时需原话确认「是否支持带独立交易模式的 MiniQMT」。

优缺点与边界

本地运行的代价与回报

低延迟与高灵活性的另一面，是需要自行运维

类别事项说明
优点延迟极低本地直连极速柜台 + 全内存交易，适合高频/套利/抢单
优点品种全覆盖唯一可做期货/期权的券商量化终端
优点代码本地保密策略不上云，保密性强
优点可装任意第三方库外部 Python 环境自由 pip，可接 AI/数据库
优点Tick 级回测逐笔回测，策略数量无硬性上限
局限需硬件常开关机/断网/死机即策略停摆，需自维护
局限编程门槛高需懂 Python + 量化 + 系统运维
局限MiniQMT 无内置回测需外接 backtrader / vectorbt
注意仅 Windows 客户端Mac/Linux 需虚拟机
注意xtquant 非开源无官方 GitHub，pip 包实为镜像/本地拷贝

重要说明

xtquant 非开源、无官方 GitHub 仓库、无正式 pip 包。 pip install xtquant 实际指向镜像或本地拷贝方案；社区 PyPI 包 quant1x-xtquant 为第三方维护。MiniQMT 软件免费但不能免开户， 实盘必须经券商开户 + 白名单 + 专业版权限。
