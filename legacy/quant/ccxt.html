什么是 ccxt？

屏蔽交易所 API 差异的统一交易库

核心定位

ccxt（CryptoCurrency eXchange Trading Library）是一个统一 API 库， 用同一套代码访问 100+ 家加密货币交易所和预测市场。核心价值是屏蔽各交易所 API 差异， 开发者只需学一套接口即可对接所有交易所，官方定位「a unified trading API」。

与 freqtrade 的关系

freqtrade 以 ccxt 作为底层交易所对接层：freqtrade 的 Exchange 类是 ccxt 的封装， 同时初始化同步和异步两个 ccxt 客户端。一句话：freqtrade 负责策略与回测，ccxt 负责统一对接交易所。
