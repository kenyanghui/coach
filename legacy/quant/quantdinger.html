核心运行角色

当前官方Compose将长任务与长生命周期交易状态拆开，避免所有工作挤在单一Web进程。

backend：Human API、Agent Gateway和核心服务入口
trading-worker：策略运行时、订单、券商会话与对账
celery-worker：AI、回测、实验、报告等有限任务
scheduler-worker / celery-beat：计划任务与调度
PostgreSQL / Redis：持久状态、缓存、队列和任务支撑

DELIVERABLE COURSE

QuantDinger八步全链路实训

每一步都有课堂动作、交付物和验收点。任何真实交易连接都不作为基础班必做内容。

LESSON 00

安全预检

检查Docker、端口、磁盘、管理员凭据策略、加密密钥和备份位置。

交付：《部署前检查表》；验收：不展示任何真实密钥值。

LESSON 01

本地部署与健康检查

启动Compose栈，确认Web、Mobile、API、数据库、Redis和Worker状态。

交付：服务状态截图与健康检查日志。

LESSON 02

数据与市场目录

配置一个数据源，理解标的规范、K线、基础数据和更新频率。

交付：一个标的的数据字典与时间戳记录。

LESSON 03

Python Strategy API V2

编写最小策略，掌握初始化、订阅、参数、状态、信号和订单意图。

交付：可执行策略文件与参数说明。

LESSON 04

回测与诊断

设置成本、滑点、区间和基准，检查收益、回撤、换手与失败样本。

交付：《回测证据包》与反例分析。

LESSON 05

Paper Trading

在模拟模式观察策略运行、订单、成交、持仓、停止条件和状态恢复。

交付：模拟运行日志与执行偏差表。

LESSON 06

Agent Gateway与MCP

创建最小权限token，让Cursor、Claude Code或Codex调用获批工具。

交付：MCP调用记录；验收：客户端看不到券商凭据。

LESSON 07

监控、停止与复盘

设计服务监控、策略停止、失败恢复、备份和复盘模板。

交付：《运行手册》与故障演练记录。
