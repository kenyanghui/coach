什么是 OpenBB？

从迷因股终端到企业级金融数据平台的十年进化

核心定位

OpenBB（Open Data Platform，ODP）是一个免费、完全开源的金融数据平台， 把专有、授权与公开的数据源统一接入一个标准化的数据层，再通过「connect once, consume everywhere」 一次性暴露给多个消费端：Python 环境、OpenBB Workspace、Excel、MCP 服务器、REST API。

其前身 Gamestonk Terminal 诞生于 2021 年初的迷因股热潮，由软件工程师 Didier Lopes 发起，在 Hacker News 与 Reddit 走红后，于 2022 年 3 月成立 OpenBB Inc.， 现已转型为 Bloomberg Terminal 的开源替代方案。

统一命名空间约定

所有调用遵循层级命名空间：obb.<模块>.<子类>.<方法>， 例如 obb.equity.price.historical("AAPL")。 数据源通过 provider= 参数切换，同一个方法签名可跨 31 个数据源复用。

安装与配置

三步接入 OpenBB

从零到真实数据调用，不到 5 分钟

1 安装核心包（Python 3.10 – 3.13）
# 安装全部数据源（推荐）
pip install "openbb[all]"

# 或仅安装核心
pip install openbb
2 Python SDK 直接调用
from openbb import obb

# 获取苹果历史行情
output = obb.equity.price.historical("AAPL")
df = output.to_dataframe()   # 转 DataFrame

# 切换数据源（默认 yfinance）
obb.equity.price.historical("AAPL", provider="fmp")
3 启动本地 REST API 服务
# 启动 FastAPI 服务（Uvicorn，端口 6900）
openbb-api

# 浏览器访问
http://127.0.0.1:6900
API Key 配置

免费数据源（如 yfinance、fred）无需密钥即可使用； 付费数据源（如 polygon、fmp）需通过 obb.account.save(pat="<token>") 或环境变量配置 API Key。 认证凭据加密存储，绝不写入源码。

许可证与边界

AGPL-3.0 · 开源但有条件

理解授权边界，才能放心地在生产环境中使用

类别事项说明
允许内部使用 / 研究 / 开发无任何限制，完全免费
允许私有扩展与专有数据源可闭源集成自有数据，无需公开
允许作为依赖调用仅调用 OpenBB API，风险较低
受限修改后对外分发需以 AGPLv3 开源，或购买商业许可证
受限作为 SaaS 对外托管网络分发触发 AGPL copyleft 条款
注意付费数据源需订阅Polygon / FMP / Intrinio 等需单独付费
注意数据仅供参考不构成投资建议，交易存在高风险
商业对比

相较于 Bloomberg Terminal 的 ~2,000 美元/用户/月，OpenBB 核心零席位费， 无供应商锁定，数据完全主权可控。企业需要 RBAC、SSO/SAML、审计日志、VPC 部署时， 可升级到 OpenBB Workspace Pro（SOC 2 Type II 认证）。
