# 万丰视角意见书：量化工具研究如何服务万丰 CIO（2026-10-07）

> 承接《量化工具领域研究可行性报告》（docs/quant-tooling-feasibility-2026-10-07.md）。
> 本文只回答一个问题：**这些研究怎么让万丰 APP 的种子用户更值钱**。
> 前提边界（owner 拍板）：万丰能力后台 = DSA + 舆情智察（cn-financial-scraper）；
**不接 QuantDinger**。

## 一、产品现状与研究的关系

万丰 CIO 正处于「去 bug → 种子用户服务」期，此刻的产品动作要**克制**：一切研究产出
以「数据/内容增强」形态进入现有模块，不新增系统面。对应关系：

| 研究线 | 进入万丰的形态 | 不做什么 |
|---|---|---|
| W1 数据底座（a-stock-data/easy-tdx） | 舆情智察的数据备源 + DSA 的交叉验证源 | 不另起行情服务，不碰 QuantDinger |
| W2 Kronos×玄学量化 | 远期「卦象视图」（舆情智察的展示层创新） | 不做预测信号推送（合规+产品克制） |
| W3 技能包（体检/复盘/雷达） | 舆情智察的三个增值技能，跑批在矩阵 | 不进 APK 交互层 |
| W4 内容 | coach 站引流 + 万丰品牌专业度 | 不在站内提玄龙堂（护栏已验证） |

## 二、四条具体意见

1. **种子期的「啊哈时刻」建议押注舆情智察而不是行情**。行情家家都有，舆情智察
   （机构舆情+个股新闻+（远期）卦象视图）是差异化面。W1 数据底座直接给它补弹药：
   a-stock-data 的研报层/信号层（龙虎榜/北向/解禁）可作为舆情智察的「数据侧写」，
   让同一个机构的页面既有新闻又有资金面上下文——一个接口讲完一个故事。
2. **Kronos 课题的万丰路径分三步走**：POC（矩阵 Xuan）→ 卦象因子回测报告（coach
   站首发内容，蹭 AAAI 热度）→ 数据面稳定后才考虑产品化「卦象视图」。**任何阶段
   都不输出买卖建议**——这是产品合规底线，也是玄学量化「可证伪」纪律的品牌资产。
3. **技能生态是万丰的护城河候选**：quantskills/AlphaGBM 证明「技能化投研」正在
   起量。W3 的三个技能（体检/复盘/雷达）按 SKILL.md 标准写，跑在矩阵 opencode
   上——未来可以开放给种子用户「自带技能」（类似 Claude 技能市场），这是 APP
   之外的第二增长曲线种子。
4. **gainlab 立项的商业启示要「取其形去其险」**：其获客-转化链路（信号内容→社群
   →会员）可借鉴为「合规版投教内容 + 工具订阅」，但其外汇/黄金信号带单业务在国内
   监管红线内**明确不做**（详见 hermes 节点立项研究）。万丰的订阅门（会话+订阅双门）
   已具备商业闭环的技术形态。

## 三、节奏建议（与种子期同步）

- 本周：W1 收尾（easy-tdx 冒烟）+ W2 POC 出报告 → 舆情智察数据侧写上线（不改
  架构，只加数据）
- 下周：W3 三技能进矩阵跑批 + W4 内容页发布（coach 站）
- 两周后：以种子用户反馈决定「卦象视图」是否立项产品化

## 四、风险红线（重申）

- 预测/信号不直连用户投资建议；玄学量化的一切产出以「可回测的研究」呈现
- 数据源低频+缓存+TOS 合规；easy-tdx 仅研究用途
- 内容站（coach）与产品（万丰）品牌隔离已由 drift guards 保证
