## ③ 技术栈
- 形态：单文件 `SKILL.md`（结构化 Markdown + 内嵌 Python），兼容 **Claude Code / Codex / OpenClaw** 及任何支持上下文注入的 AI 助手
- 依赖（README）：`mootdx requests pandas stockstats numpy baostock xlrd openpyxl`；V3.0 起移除 akshare，V3.9 未新增依赖
- 架构：**15 层**、**87 个端点（82 主 + 5 备胎）**、**34 个数据源**；除 mootdx/baostock（TCP 客户端）外全部直连 HTTP，不经第三方封装
- 鉴权：**除 iwencai 语义搜索外全部免 Key**（东财系内置 `em_get()` 串行限流防封）
- 验证：`python3 -m unittest discover -s tests`（V3.10.1 共 173 条离线测试）；真实网络测试需显式开关

## ④ 数据面与 A 股适用性
覆盖 15 类（README）：
1. 行情/K 线：实时价、PE/PB/市值/换手率、日周月前后复权与 1~60 分钟 K 线、全市场当日日线、当日逐笔、复权因子、指数/ETF
2. 研报：个股/行业研报与 PDF、评级、三年 EPS 预测、一致预期、NL 检索
3. 市场信号：强势股题材归因、北向、板块归属、资金流、龙虎榜、解禁、行业排名
4. 资金面/筹码：两融、大宗、股东户数、分红、120 日资金流、筹码分布 CYQ、ETF 份额
5. 新闻：个股新闻、财联社电报、7×24 快讯、新闻联播文字稿
6. 基础财务：季报快照、F10、财报三表、估值历史、上市退市日、申万行业变迁、ST 名单
7. 公告：沪深北全量公告
8. 打板：涨停/炸板/跌停/昨涨停池、涨停原因、重点监控、日内异动
9. ETF 期权：T 型报价、希腊字母、隐含波动率
10. 舆情互动：互动易、上证 e 互动、热榜、人气榜、概念命中
11. 宏观利率：社融、PMI、国债/信用债曲线、FR/FDR、LPR、全球宏观日历
12. 指数与交易日历：中证/国证成分与权重、中证 PE 与股息率、深交所交易日历
13. 期货大宗：五大交易所官方日行情、商品/股指期权、会员持仓、实时期货、A50、上海金、期货日 K（含大商所）
14. 事件驱动：业绩预告、机构调研、增减持、回购、股权质押、新股申购
15. 可转债：条款、转股价、转股价值、溢价率、状态

A 股适用性：**极强**，是为 A 股 + AI Agent 量身定做的数据底座；对北交所、ST、复权、前视偏差（申万行业变迁/历史估值）等 A 股特色问题有专门处理与 FAQ。

## ⑤ 核心能力
- 用自然语言激活取数（「帮我看看 688017 的估值」等），无需记接口参数
- 内置 4 套调研流程：单票估值（30s）、批量对比、主题研报、新标的调研
- 多源冗余 + 备用源降级策略（东财被封可切交易所官方/新浪/同花顺）
- 与聚宽代码互转（`to_joinquant()`），历史估值/行业归属防未来函数

## ⑥ 与「A 股投研 + 万丰 CIO」契合度：**5 / 5**
理由：直接命中 A 股投研的取数刚需，覆盖面在同类开源项目里罕见；零鉴权、可本地跑、对东财风控有工程化防护；既能喂给 AI Agent 做研究，也能导出数据给自建因子/回测管线。对 CIO 而言是低成本、可快速验证的 A 股数据中台替代/补充。唯一需注意：**它只负责取数，不带回测引擎**。

## ⑦ 集成难度与路径
- 难度：**低**。`mkdir -p ~/.claude/skills/a-stock-data` → 放入 `SKILL.md` → `pip install` 依赖
- 路径：
  1. POC：装成 Skill，用内置流程验证几只标的取数质量
  2. 数据落地：把端点输出接进团队已有的因子/回测框架或聚宽
  3. 生产中：调大 `EM_MIN_INTERVAL`、配置代理/多网络，避免东财 IP 风控；关键数据配独立备胎

## ⑧ 风险
- **合规/稳定性**：大量数据来自非官方 HTTP 接口（腾讯/东财/同花顺等），上游随时可能变更或反爬（README 已记录 mootdx K 线 2026-09 失效、同花顺行业接口 401 等）
- 东财系共用风控，IP 被封会成片失联（#18）；大陆住宅宽带偶发 HTTP 000
- 单文件体积大，对 token 敏感的环境需改按需读取
- 不提供回测/组合优化，需自建；数据源准确性需自行对账
- 作者个人项目（README 含求职信息），虽活跃但存在单点维护风险
