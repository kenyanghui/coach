# 个股体检（stock-checkup）

## 输入
- `symbol`：6 位 A 股代码（必填）
- `days`：回看天数（默认 7，1–30）

## 步骤
1. 取数：`curl -s "http://127.0.0.1:9031/api/intel/news?symbol=<symbol>"`（演示实例；
   生产 :9001 需会话）。返回 `items[]`（新闻标题/新闻内容/文章来源/发布时间/新闻链接）。
2. 统计（在本地对 items 计算）：
   - 消息密度：`len(items)` 条/N 天，日均值
   - 情绪面：对标题做关键词分类（正/负/中性词表各 ~20 词起步，可迭代）
   - 风险词命中：立案/调查/减持/质押/违规/诉讼/退市/警示/冻结/爆雷
   - 来源分布：按 文章来源 聚合计数
3. 输出体检卡（markdown）：

```
# 个股体检卡 <symbol>
| 维度 | 结果 |
|---|---|
| 消息密度 | X 条/日（N 天共 M 条） |
| 情绪面 | 正面 a / 负面 b / 中性 c |
| 风险词 | 命中 n 条（列出） |
| 主要来源 | top3 |
```

4. 附最近 5 条标题（带链接），末行注明：`数据：万丰舆情智察（东财）· 仅研究参考，不构成投资建议`。

## 验收
- 一条命令出卡；数据缺失时如实写「无数据」，禁止编造。
