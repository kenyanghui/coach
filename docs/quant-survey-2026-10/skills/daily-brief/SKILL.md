# 每日复盘（daily-brief）

## 输入
- `symbols`：逗号分隔代码列表（如 `600519,300750,002463`）或文件（每行一代码）

## 步骤
1. 逐个取数：`curl -s "http://127.0.0.1:9031/api/intel/news?symbol=<code>"`
2. 生成日报：

```
# 复盘简报 <日期>
## <代码> <名称>
- 消息 n 条 · 情绪倾向：正 x / 负 y
- 风险词：…（若有）
- 要闻 top3（标题+链接）
## 全局提示
- 跨标的风险词汇总（如多家命中"减持"）
```

3. 末行免责声明同 stock-checkup。

## 部署建议
- 矩阵节点 cron：`0 17 * * 1-5`（交易日收盘后），产物推 Gitea 或发飞书机器人
