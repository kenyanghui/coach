什么是 Backtrader？

纯 Python 的事件驱动回测框架

核心定位

Backtrader 是 Daniel Rodriguez（@mementum）开发的纯 Python 事件驱动回测框架，2015 年 1 月开源。最初只是一个单文件 bt.py， 后来成长为功能最全的 Python 回测框架之一，官方描述为「Python Backtesting library for trading strategies」。

一个有趣的彩蛋：版本号末段数字即内置指标数量——1.0.0.21 = 21 个指标起步， 到 1.9.76.123 时达到 123 个指标。原项目 2023 年起实质停维，社区 fork backtrader2 续命。

1 安装
pip install backtrader
pip install backtrader[plotting]   # 含 matplotlib 绘图
2 典型策略骨架
import backtrader as bt

class MyStrategy(bt.Strategy):
    def __init__(self):
        self.sma = bt.indicators.SimpleMovingAverage(self.data.close, period=20)
    def next(self):
        if self.data.close[0] > self.sma[0]:
            self.buy()   # 金叉买入

cerebro = bt.Cerebro()
cerebro.addstrategy(MyStrategy)
cerebro.adddata(bt.feeds.PandasData(dataname=df))
cerebro.broker.setcash(100000)
cerebro.run()
cerebro.plot()
核心对象

Cerebro（引擎）· Strategy（策略）· DataFeed（数据）· Broker（券商）· Analyzer（分析器）· Indicator（指标）· Observer（观察者）· Sizer（仓位管理）。 索引约定：0 = 当前，负数 = 过去，正数 = 未来。

黄金搭档

Backtrader 回测 + xtquant 数据/实盘

免费行情 + 回测 + 交易的完整闭环

为什么是黄金搭档

xtquant（迅投 QMT）提供 xtdata 行情 + xttrader 实盘， 但本身不支持回测——这正是它与 Backtrader 互补的关键。 组合闭环：免费行情（xtdata）+ 回测（backtrader）+ 实盘（xttrader）， 实现「免费 + 回测 + 交易」完整链路，被社区称为「平民量化黄金搭档」。
