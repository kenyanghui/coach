什么是 Zipline？

Quantopian 的美股事件驱动回测引擎

核心定位

Zipline 是众包对冲基金 Quantopian 开发的 Pythonic 事件驱动回测引擎， 主要用于美股多因子/量化策略研究。标志性能力是 Pipeline API—— 声明式的横截面因子计算。Quantopian 2020 年底关闭后原项目停维， 现由 Stefan Jansen 的 zipline-reloaded fork 续命（3.1.1 版本，活跃维护）。

研究流水线

典型工作流：zipline Pipeline 计算因子 → Alphalens 分析因子有效性 → zipline 回测 → pyfolio 生成业绩报告。 这是 Quantopian 当年留给业界最完整的因子研究体系。

安装

pip install zipline-reloaded

原版无法在现代 Python 安装

1 安装 reloaded 版
pip install zipline-reloaded   # Python ≥3.10
⚠️ 重要

原始 zipline 依赖栈极旧（Python 2.7/3.5/3.6、pandas≤0.22），现代环境基本无法直接安装。 必须使用 zipline-reloaded（Python 3.10+、numpy 2.x、pandas 2.x）。
