什么是 PTrade？

恒生电子旗下的券商托管式量化交易终端

核心定位

PTrade（Professional Trade）是恒生电子（600570.SH）控股子公司 杭州云纪网络科技研发的专业级量化交易终端，属恒生「i私募」产品线。 它融合恒生极速柜台的高并发、低时延能力，提供「量化投研 → 回测 → 仿真 → 实盘」全流程服务。

核心特征是云端托管（券商托管）——策略代码上传至券商机房服务器运行， 本地电脑关机、断网、休眠均不影响执行，支持 7×24 小时无人值守。 软件约 2019 年推向市场，官方表述「已在近 40 家券商上线」。

事件驱动编程模型

策略采用事件驱动，核心生命周期函数： initialize()（启动一次）→ before_trading_start()（盘前）→ handle_data()（盘中，日线默认 14:50 触发）→ after_trading_end()（盘后）。 高频扩展支持 tick_data()（约 3 秒）与 run_interval()（自定义间隔 ≥3 秒）。

其他竞品定位

聚宽（JoinQuant）：数据+社区驱动的研究型平台，适合研究/回测/学习，实盘自动交易弱。

PTrade 定位夹在两者之间：券商托管的一体化实盘终端，更适合股票/ETF/可转债的中低频策略与零代码用户。

收费与开通门槛

软件免费 · 佣金另计

「免费」的准确含义与真实开通条件

收费模式

软件使用权免费：PTrade 客户端本身免年费/授权费，多数券商不收取。 仍需支付：交易佣金（可协商「万一免五」「万 0.5、0.1 元起收」等低佣）、印花税、规费； Level-2 / Tick 行情部分券商收费；恒生 LDP 极速柜台一般不再额外收费。

条件典型要求
资金门槛主流 10 万 – 50 万（国金 ~10 万最低档，华泰 ~20–50 万，国泰君安/招商/中信 ~50 万）
风险测评C4（积极型）及以上，部分券商要求 C5
交易经验部分要求半年以上
开通流程联系客户经理 → 专属链接开户 → 入金达标 → 签署《量化交易风险揭示书》→ 审核 1–3 个工作日 → 下载客户端
合规报备按证监会《程序化交易管理规定》「先报告、后交易」，软件名称/版本/策略类型/最高申报速率等需报备
重要提醒

资金门槛「10 万 vs 50 万」、期货/期权支持、Level-2 是否免费，均存在不同券商间差异， 实际以开户券商客户经理确认为准。切勿通过自助渠道开户，需走专属量化白名单通道。

优缺点与边界

理解边界，才能用好工具

云端托管的便利，也带来灵活性与保密性的代价

类别事项说明
优点云端托管无人值守7×24 运行，本地关机/断网不影响，运维成本几乎为零
优点低门槛 / 零代码15+ 工具模板 + 图形化拖拽 + Python 三种方式
优点DeepSeek AI 编程自然语言生成策略代码，调试耗时减少 60%
优点回测→实盘无缝毫秒级报单，券商托管稳定性强，全栈信创适配
局限不能装第三方库策略逻辑受内置 API 白名单约束，灵活性受限
局限代码上传券商服务器存在策略保密性顾虑
局限回测分钟级为主不适合高频/打板/套利等速度敏感策略
局限策略数量受限实盘约 8 个、模拟约 5 个
注意仅 Windows 客户端Mac/Linux 需虚拟机
注意版本碎片化各券商版本 API 行为不一致（订单状态字段类型、期权支持度等）
