什么是 FinRobot？

AI4Finance 基金会开源的金融大模型 Agent 框架

核心定位

FinRobot 是由 AI4Finance Foundation 开发的开源金融 AI Agent 平台， 受到微软研究院（Microsoft Research）和哥伦比亚大学等机构的学术支持。 它将大语言模型（LLMs）、强化学习与量化分析统一到四层架构中， 通过 Financial Chain-of-Thought（FinCoT） 推理机制， 将复杂的金融问题分解为可执行的逻辑步骤。

首个专门针对股票研究（Equity Research）的多 Agent 框架， 生成的研报深度可与 JPMorgan、UBS 等顶级券商媲美。 集成 Microsoft AutoGen 实现多 Agent 对话编排， 支持 FinGPT / Llama / ChatGLM / Falcon 等模型即插即用。

系统架构

四层架构 · 金融 CoT 推理

从模型底座到 Agent 应用层的完整技术栈

L4
Financial AI Agents Layer · 金融 AI Agent 层
Financial CoT 推理将复杂金融问题分解为逻辑步骤。包含市场预测 Agent、文档分析 Agent、交易策略 Agent，每个 Agent 具备 Perception → Brain（LLM+CoT）→ Action 三层模块
L3
Financial LLMs Algorithms Layer · 金融大模型算法层
动态配置模型应用策略：FinGPT（金融情感）、Llama（美股市场）、ChatGLM（中国市场）、Falcon（金融关系分析），以及多模态模型与 FinRL（组合优化）
L2
LLMOps & DataOps Layer · 模型与数据运维层
多源集成 + Smart Scheduler 智能调度。根据任务表现动态切换通用/微调 LLM，确保最优模型选择。训练、微调和实时数据处理流水线
L1
Multi-source LLM Foundation Layer · 多源大模型基础层
插件式集成 7B~72B 参数的各类型 LLM：FinGPT、Llama、Falcon、ChatGLM 等。形成平台的计算与推理基础

安装与配置

三步部署 FinRobot

从零到第一个金融 Agent 运行

1 环境准备 & 安装
# 创建 conda 环境（Python 3.10）
conda create --name finrobot python=3.10
conda activate finrobot

# 克隆仓库
git clone https://github.com/AI4Finance-Foundation/FinRobot.git
cd FinRobot

# 安装
pip install -U finrobot
# 或开发模式：
pip install -e .

# 股票研究模块额外依赖
pip install -r requirements-equity.txt
2 配置 API Keys
# 编辑 OAI_CONFIG_LIST — 配置 LLM（OpenAI/Azure/本地模型）
cat OAI_CONFIG_LIST

# 编辑 config_api_keys — 配置金融数据源
cat config_api_keys
# 必填：FINNHUB_API_KEY / FMP_API_KEY / SEC_API_KEY
3 运行 Demo
# 市场预测 Agent — 预测股价涨跌
jupyter notebook tutorials_beginner/agent_fingpt_forecaster.ipynb

# 金融分析师 Agent — 从 10-K 生成微软研报
jupyter notebook tutorials_beginner/agent_annual_report.ipynb

# RAG 问答 — 基于财报/电话会的智能 Q&A
jupyter notebook tutorials_beginner/agent_rag_qa.ipynb

# 多模态图表 — K 线图智能分析
jupyter notebook tutorials_advanced/lmm_agent_mplfinance.ipynb
必需 API 密钥

LLM：OpenAI API Key（或 Azure / 兼容的本地模型） · 金融数据：FINNHUB_API_KEY + FMP_API_KEY（Financial Modeling Prep） · SEC 文件：SEC_API_KEY（sec-api.io） · 可选：Yahoo Finance（免费，无需 key）、OpenBB、Reddit

协同使用建议

FinRobot 擅长美股深度研究（SEC 文件分析 → 三 Agent CoT → 自动研报输出）， 适合需要研究叙事和投资论点的场景。
Pandadata + PandaAI 擅长中文市场全覆盖（A 股/期货/期权/宏观数据 → 策略回测 → 多 Agent 交易决策）， 适合需要精准数据 + 交易执行的场景。
两者互补：FinRobot 做美股研报生成，Pandadata 做中文市场数据与策略，覆盖全球量化投研。
