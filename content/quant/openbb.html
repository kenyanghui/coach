什么是 OpenBB？

免费开源的「彭博终端」替代品

核心定位

OpenBB 是一个免费、完全开源的投资研究平台， 被称为「彭博终端（Bloomberg Terminal）的开源替代品」。 最初以 OpenBB Terminal（600+ 命令的金融终端）为核心， 配套 OpenBB SDK（程序化访问），现在正转型到 OpenBB Platform。

覆盖股票、期权、加密、外汇、宏观、固收、另类数据等 11 大资产类别， 支持 Alpha Vantage、FRED、Polygon、Binance、IEX、Finnhub 等 10+ 数据源。

安装与使用

三种安装方式

从源码、Docker 到桌面安装器

1 安装 Platform / SDK
# 安装 OpenBB Platform
pip install openbb
# 或安装 CLI
pip install openbb-cli
# 或旧版 SDK（v3.2.4）
pip install openbb==3.2.4
2 配置数据源 API Key
# 配置数据源（Alpha Vantage / FRED / Polygon / Finnhub 等）
openbb.keys
3 使用示例
# SDK 调用
from openbb_terminal.sdk import openbb
df = openbb.stocks.load("AAPL")

# 终端命令
stocks/load AAPL/candle
