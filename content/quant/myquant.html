什么是掘金？

面向机构与专业量化投资者的本地化一站式平台

核心定位

掘金（MyQuant）是深圳红树科技（2013 年成立，法定代表人许强）运营的 本地化一站式量化投资平台，覆盖投研、回测、仿真、实盘、风控、绩效分析全流程。 核心卖点是机构级高性能回测引擎 + 期货/CTA 强 + 多语言支持。

2016 年平台正式上线，先后获九州证券、东方财富资本投资。 是四大量化平台（QMT/PTrade/聚宽/掘金）中期货 CTA 能力最强的选手。

SDK 与 API

gm 库 · 闭源二进制

Python 层源码可见，底层引擎闭源

1 安装 gm SDK
pip install gm -U -i https://mirrors.aliyun.com/pypi/simple/
# 交易 SDK（仿真/实盘）
pip install gmtrade
2 认证并使用
from gm.api import *
set_token('你的token')
# 获取历史行情
history('SHSE.600000', frequency='1d', fields='close', start_time='2024-01-01')
开源状态

掘金 SDK 未声明开源。Python 层源码安装后可见（site-packages/gm/api/）， 但底层为平台相关二进制 wheel（含编译的本地扩展），核心引擎闭源。 GitHub 仅有策略示例仓库 myquant/strategy，无 SDK 源码。
