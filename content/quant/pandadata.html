什么是 Pandadata？

一个以 AI Agent 为中心的量化金融数据技能生态

核心定位

Pandadata（SDK 名称 panda_data）是一个量化金融数据平台， 通过 Python SDK v0.0.12 提供 218 个中文文档数据接口， 覆盖 A 股、港股、美股、期货、期权、宏观、基金、量化因子等维度。

skill-pandadata-api 将其打包为 Agent Skill——让 Claude Code、WorkBuddy、Cursor 等 AI 编程助手 能够用自然语言精准查询金融数据，无需记忆接口名称和参数。 配合 Quantskills.ai 平台，可完成从数据获取到策略评估的完整量化投研闭环。

平台定位

PandaAI（pandaaiquant.com） 是一个 AI 驱动的量化交易平台， 致力于降低量化投研门槛。从自然语言生成策略到多 Agent 协作决策，从单兵作战到组建 AI 量化团队， 覆盖「数据→因子→回测→风控→执行」完整链路。与 Pandadata 数据底座和 QuantSkills 技能生态构成三位一体的量化基础设施。

安装与配置

三步接入 Pandadata

从零到真实数据调用，不到 5 分钟

1 克隆仓库 & 安装依赖（需 Python ≥ 3.10） 
# 克隆 skill 仓库
git clone https://github.com/quantskills/skill-pandadata-api.git pandadata
cd pandadata

# 创建虚拟环境 & 安装依赖
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
2 检索接口（无需凭证，纯离线文档查询） 
# 列出全部 218 个方法
.venv/bin/python scripts/search_api_docs.py --list-methods

# 查看 get_stock_daily 的完整参数/字段/示例
.venv/bin/python scripts/search_api_docs.py --method get_stock_daily

# 关键词检索（多个词需命中同一行）
.venv/bin/python scripts/search_api_docs.py 股票 分红 --context-lines 4
3 配置凭证 & 真实调用（需注册 Pandadata 账户） 
# 交互式配置凭证（隐藏输入密码）
.venv/bin/python scripts/setup_runtime.py

# 真实 API 调用（自动加载凭证）
.venv/bin/python scripts/call_api.py \
  --method get_stock_daily \
  --params '{"symbol":["000001.SZ"],"start_date":"20250101","end_date":"20250131","fields":[]}'

# Python SDK 直接调用
from pandadata_runtime import init_pandadata
panda_data = init_pandadata()  # 自动加载凭证并登录
df = panda_data.get_stock_daily(symbol=["000001.SZ"], ...)
认证机制

SDK 0.0.12 通过 init_token(username, password, base_url) 完成认证； 凭证可保存在 ~/.pandadata/pandadata.env（600 权限）或通过环境变量传入： DEFAULT_USERNAME / DEFAULT_PASSWORD / JAVA_SERVICE_BASE_URL。 传入明文密码，SDK 内部自行哈希；加密凭证持久化到 user.json，token 仅存内存。

注意事项

关键限制与最佳实践

了解边界，才能更好地使用工具

类别限制项说明
SDK17 个接口未导出优先股数据及部分公司行为接口在 SDK 0.0.12 中不可通过 get_* 调用
SDK6 个方法名变更如 get_stock_competitor → get_stock_competitor_information，call_api.py 自动拒绝旧名
数据需要注册账户调用真实数据需 pandadata 凭证，非免费开放；技能包代码本身开源 GPL-3.0
数据非实时数据仅供研究参考，不构成投资建议；无 tick 级别数据
数据日期范围限制开始与结束日期间不超过 5 年
最佳先查再答API 相关问题先检索文档，不凭 LLM 记忆
最佳取数与分析分离先获取并验证 DataFrame，再做转换/分析
最佳空数据先自查返回空时先核对日期范围、代码格式、必填过滤，再判定服务异常
