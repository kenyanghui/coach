Coach Skills 技能系统

每位 AI Coach 的"专业能力"通过 Paperclip 的 Skills 系统定义。每个 Skill 是一份 Markdown 文件，包含完整的教练框架、对话协议和评估标准。

🧠 认知思维教练 · Skill
# cognitive-coach.md ## 教练框架 - 第一性原理思考法 - 金字塔原理 - 系统思维 × 思维模型库 ## 对话协议 1. 明确议题与目标 2. 识别思维假设 3. 应用思维模型拆解 4. 形成可执行的思维方案 ## 评估标准 - 思维清晰度提升 - 问题拆解能力 - 决策质量改善
💗 情绪智力教练 · Skill
# ei-coach.md ## 教练框架 - Genos 六维模型 - EI 自我觉察 → 他人觉察 - 情绪管理 → 情绪运用 ## 对话协议 1. 情绪识别与命名 2. 触发情境分析 3. 重构情绪叙事 4. 建立新应对模式 ## 评估标准 - EI 测评分数变化 - 情绪调节能力 - 人际关系质量
✍️ 一次编写 Skill → 所有 Coach Agent 复用 → Git 版本管理 → 持续迭代优化

为什么是 Paperclip？

平台定位优势
Paperclip + OPCAI 教练公司 OS组织架构 · 预算控制 · 审计日志 · Web UI · 多客户隔离
直接写 Claude Code单 Agent灵活但无编排，每人每次都要配环境
OpenClaw 技能单 Agent + Skills无组织架构，无预算管理，无多客户隔离
其他 Agent 平台通用编排面向开发者，无教练行业模板
✅ Paperclip 带来的核心能力
• 组织架构 — CEO Coach 自动管理教练团队
• 心跳调度 — 教练按计划执行对话任务
• 预算控制 — 每个客户有独立预算，超限自动暂停
• 审计日志 — 每一步教练对话可追溯
• 多公司隔离 — 一次部署服务多家客户
• Web UI — 可视化看板，非技术人员也能运营
⚠️ 需要关注的挑战
• AI Coach 需要精心设计的 Skill 和提示词
• 教练质量监管仍需人类督导参与
• 敏感话题（心理危机等）需要人工交接机制
• 大规模并发教练对话的性能开销

Paperclip 核心概念

快速理解 Paperclip 的关键设计理念。

核心
组织架构图
树状命令链——CEO 可以"招聘"CTO，CTO 再"招聘"工程师。每一级管理者自主决策是否招募子 Agent
P1
目标对齐
每个任务携带完整上下文，Agent 知道"为什么做"
P2
心跳调度
Agent 按计划唤醒（3600s/600s/86400s），也支持事件驱动
P3
原子预算控制
每月限额 → 80% 预警 → 100% 硬停止，防止费用失控
P4
不可变审计日志
追加式日志，记录每一步决策和输出，可追溯可复盘
P5
多公司隔离
一次部署可运行多个完全隔离的"公司"——每个客户一个组织
每个客户 = Paperclip 中的一家独立"公司" · 每位 Coach = 一个 Agent · 每次对话 = 一笔有预算的 task
