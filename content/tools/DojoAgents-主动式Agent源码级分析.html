⚙ 三、主动式 Agent 的六大核心机制

DojoAgents 的"主动性"不是单一特性，而是由六层机制叠加而成的系统行为。

🔄
机制 1: Agent Loop — 循环认知引擎
agent/loop.py · 1523行
Strands Agent 驱动的多轮推理循环：推理→行动→观察→再推理，直到达到目标或达到迭代上限。
✅
机制 2: Harness 系统 — 自动验证与纠错
agent/harness.py · 167行 (+ 3个实现)
Agent 产出后自动验证是否满足任务要求，不满足则自动注入引导提示并继续，最多恢复8轮。
⚡
机制 3: 事件驱动自动化
utils/event_bus.py · 仅23行!
发布/订阅模式解耦。工具失败→自动修复，大数据量→自动分析，复杂任务→自动规划。
📋
机制 4: Auto Plan — 自动规划执行
planning/automation.py · 149行
LLM 自动将复杂请求拆解为多步骤计划，DAG 依赖排序后逐步执行，并综合所有步骤生成最终回答。
👥
机制 5: Multi-Agent 自动调度
multi_agent/ · 9个文件
正则检测用户消息复杂度，自动激活多 Agent 模式（analyst / implementer / reviewer）。工具失败自动 spawn Reviewer 修复。
⏰
机制 6: Cron Scheduler — 定时自主运行
cron/ · 2个文件 · 169行
APScheduler 驱动，Agent 在后台按计划自主执行并推送到 Slack/Telegram/微信/邮件。"在你睡觉时也在工作"。

# harnesses/tool_orchestrated.py:62-96
def validate_progress(self, state) -> HarnessDecision:
    # 1. 检查输出 Schema 验证 — 如果合法则完成
    filename, issues = self._output_write_issues(state)
    if filename and not issues:
        return HarnessDecision(complete=True)

    # 2. 引导下一步操作
    if not state.tool_results:
        issues.append("Start with get_market_overview.")
    elif not has_tool(state, "get_sector_movers"):
        issues.append("Call get_sector_movers before web_search.")
    elif not has_tool(state, "write_session_file"):
        issues.append("Finish by writing output with write_session_file.")

    # 3. 返回决策 — 允许继续但指定下一步
    return HarnessDecision(
        complete=False,
        issues=issues,
        next_steps=issues[:1],
        allow_extra_steps=True,  # ★ 关键: 允许继续
    )

6.1 事件总线源码

# utils/event_bus.py — 仅 23 行!
class EventBus:
    def __init__(self):
        self._subscribers: dict[str, list[Callable]] = {}

    def subscribe(self, event_type: str, handler: Callable) -> None:
        self._subscribers.setdefault(event_type, []).append(handler)

    async def publish(self, event_type: str, payload: dict) -> list[Any]:
        results = []
        for handler in self._subscribers.get(event_type, []):
            res = await handler(payload)
            if res is not None:
                results.append(res)
        return results

event_bus = EventBus()  # 全局单例

💡 九、构建主动式 Agent 的六大洞察

🔄
1. 循环 > 单次
主动式 Agent 的核心不是更聪明的模型，而是让模型进入一个持续运行的循环：推理→行动→观察→再推理。
🔧
2. 工具粒度 = 自主程度
工具越原子化，Agent 的自由度越高。每个工具应：原子化、可组合、终端状态明确。
⏰
3. 调度器 = 时间维度的主动性
apscheduler 让 Agent 有了时间感知能力——不是被提问时才工作，而是按自己的节奏持续运行。
🛡
4. 护栏 = 自主性的边界
三层防护：预防层(幻觉护栏) → 控制层(中断机制) → 终止层(循环防护)。
🧠
5. 自进化 = 长期价值
Memory + SKILL 蒸馏让 Agent 能力随使用时间增长——每次成功分析都变成可复用资产。
⚡
6. 事件解耦 = 系统可演化性
23行事件总线驱动整个自主响应体系。每个组件独立演化，通过事件松散耦合。
